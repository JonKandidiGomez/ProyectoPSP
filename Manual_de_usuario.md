# Manual de Usuario:

## 1. Menú Principal

Al iniciar la aplicación, verás el siguiente menú de opciones:

* Registrarme
* Login
* Comprar billetes
* Salir

Para seleccionar una opción, escribe el nombre de la acción (no importa si usas mayúsculas o minúsculas) y pulsa `Enter`.

---

## 2. Guía de Registro

Si es tu primera vez en el sistema, debes crear una cuenta.
Escribe `registrarme` en el menú principal y sigue las instrucciones. El sistema te pedirá los siguientes datos uno por uno. Asegúrate de cumplir con los formatos requeridos:

| Dato | Requisito / Formato | Ejemplo          |
| :--- | :--- |:-----------------|
| **Nombre** | Solo letras. | `Juan`           |
| **Apellido** | Solo letras. | `Perez`          |
| **Edad** | Un número entero. | `25`             |
| **Email** | Debe tener formato de correo válido. | `juan@email.com` |
| **Usuario** | Longitud entre **8 y 16 caracteres**. | `juanperez2025`  |
| **Contraseña**| Longitud entre **8 y 16 caracteres**. | `segura12345`    |

---

## 3. Guía de Inicio de Sesión (Login)

Para poder comprar billetes, es obligatorio iniciar sesión primero.

1.  En el menú principal, escribe `login`.
2.  Introduce tu nombre de usuario.
3.  Introduce tu contraseña.

* Si los datos son correctos: Verás el mensaje *"Te has logeado con exito!"*.
* Si no lo son: Verás *"Usuario o contraseña incorrectos"* y volverás al menú principal.

---

## 4. Guía para Comprar Billetes

Una vez que hayas iniciado sesión, puedes proceder a la compra.

1.  En el menú principal, escribe `comprar billetes`.
2.  El sistema descargará y te mostrará la **lista de billetes disponibles**.
3.  **Escribe el nombre del billete** que deseas adquirir.
4.  Pulsa `Enter`.

---

## 5. Salir

Para cerrar la aplicación de forma segura escribe `salir` en el menú principal.
